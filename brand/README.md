# 호감슬라이드 브랜드 — 결정과 파일 목록

모든 그림은 호감이 직접 만든 것(코드로 그린 SVG와 그걸 옮긴 PNG)이다. 남의 그림·아이콘을 가져오지 않는다.

## 결정 (2026-11-23)
- 로고: 지금의 모니터 로고(화면 · 십자 틈 · 받침)를 선명한 입체 블루로 다시 그림. 로고 전체에 걸친 그라데이션 하나(#6EB1FF → #3586F7 → #1B57D6)를 화면과 받침이 같이 씀 → 같은 재질. 위쪽 가장자리에 얇은 빛 테두리.
  - 십자가 만나는 가운데에만 따뜻한 빛(#FFFBEF → 투명)이 살짝 번짐. 목장노트 로고와 같은 결 (2026-11-23 호감 요청). 빛은 화면 안에만, 테두리는 또렷하게.
  - 그 밖의 흐림 그림자·광택은 넣지 않는다 (뿌옇게 보여서 로고로 안 좋음, 2026-11-23 호감 지적).
  - 고른 이유: 기존 로고를 알아보던 팀원도 같은 로고로 느끼고, 16px에서도 십자가 보임.
  - 버린 후보: 파스텔 하트·얼굴 계열(다이어리 느낌), 평면 인디고 계열.
- 첫 화면 방향 (2026-11-23 호감 결정, 앞선 '카드 세 장' 안을 바꿈): 밝은 화면에 옅은 파스텔 구름. 가운데 정렬로 위에서부터 큰 제목 한 줄(4문장이 돌아감, 휴대폰은 두 줄) → 카카오 버튼 → 워크플로우 세 단계(악보 첨부 → 가사 자동 입력 → 슬라이드 자동 완성). 요소 사이는 넉넉히 띄움.
  - 워크플로우는 그림이 아니라 실제 앱 화면 사진. 단계가 차근차근 진행되는 걸 보여 주는 게 제일 중요. 악보는 흰색. 화살표 없이 실선을 따라 파란빛이 흘러 다음 박스 테두리로 번짐.
  - 시안: `시안/첫화면-앱화면.html`. 사진을 다시 찍는 코드: `시안/앱화면-만든코드/` (팀 서버를 막고 예시 곡을 넣어 찍음. AI는 실제로 돌리지 않음).
  - 첫 화면 CSS 이름은 앱과 안 겹치게 `gv-`·`gvw-`, 움직임 이름은 앞에 g를 붙임.
  - 버린 안: 귀여운 카드 그림, 3D 책상 사진, 어두운 배경의 폭발 효과.
  - 예시 곡 가사는 호감이 지은 문장. 실제 곡 가사·성경 본문을 쓰지 않는다(저작권).
- 첫 화면 왼쪽 위 이름: 글자만 호감슬라이드 ↔ HOGAMSLIDE 로 5초마다 번갈아 나옴. 로고 그림은 고정 (2026-11-23 호감 결정).
- 문의·협업: 첫 화면 오른쪽 위 단추 → 적은 내용을 메일 앱으로 넘겨 hogamcommunity@gmail.com 으로 받음. 서버에 저장하지 않음. (서버 저장 + 알림은 나중에 다시 정함)
