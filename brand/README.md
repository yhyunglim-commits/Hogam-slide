# 호감슬라이드 브랜드 — 결정과 파일 목록

모든 그림은 호감이 직접 만든 것(코드로 그린 SVG와 그걸 옮긴 PNG)이다. 남의 그림·아이콘을 가져오지 않는다.

## 결정 (2026-11-23)
- 로고: 지금의 모니터 로고(화면 · 십자 틈 · 받침)를 선명한 입체 블루로 다시 그림. 로고 전체에 걸친 그라데이션 하나(#6EB1FF → #3586F7 → #1B57D6)를 화면과 받침이 같이 씀 → 같은 재질. 위쪽 가장자리에 얇은 빛 테두리.
  - 십자가 만나는 가운데에만 따뜻한 빛(#FFFBEF → 투명)이 살짝 번짐. 목장노트 로고와 같은 결 (2026-11-23 호감 요청). 빛은 화면 안에만, 테두리는 또렷하게.
  - 그 밖의 흐림 그림자·광택은 넣지 않는다 (뿌옇게 보여서 로고로 안 좋음, 2026-11-23 호감 지적).
  - 고른 이유: 기존 로고를 알아보던 팀원도 같은 로고로 느끼고, 16px에서도 십자가 보임.
  - 버린 후보: 파스텔 하트·얼굴 계열(다이어리 느낌), 평면 인디고 계열.
- 첫 화면 방향 (2026-11-24 호감 결정, 앞선 안을 모두 바꿈): 밝은 화면에 옅은 파스텔 구름, 가운데 정렬. 위에서부터 큰 제목 한 줄(문구 4개, 휴대폰은 두 줄) → 카카오 버튼 → 노트북 한 대 → 파일 아이콘. 요소 사이는 넉넉히 띄움.
  - 제목 효과는 강조 단어에만: 예배·교회 블러인 / 슬라이드 타자기 / 5분·호감슬라이드 형광펜 / 자동 스플릿 플랩.
  - 노트북 안에 실제 앱 화면 사진을 이어 보여 줌: ① 악보 → 가사·슬라이드 ② 말씀 → 구절·슬라이드 ③ 예배 순서 → 예배 전체 정리·슬라이드. 움직임은 화면 바뀜과 포인터 하나뿐 (복잡하지 않게, 빠르게). 애플 로고·이름은 쓰지 않음.
  - 문구 '완성된 슬라이드는 내가 원하는 파일로!' 아래 아이콘은 앱에서 실제로 받을 수 있는 형식만: TXT · 이미지(JPG, PNG) · PPTX · PDF · 투명 이미지(PNG, TGA) · CSV (뒤의 둘은 2026-11-25 호감 지시로 더함. 컴퓨터 6칸 한 줄, 휴대폰 3칸 두 줄). 아이콘은 직접 그림(애플·마이크로소프트·어도비 것 아님).
  - 사진을 다시 찍는 코드: `시안/앱화면-만든코드/` (팀 서버를 막고 예시 곡을 넣어 찍음. AI는 실제로 돌리지 않음).
  - 첫 화면 CSS 이름은 앱과 안 겹치게 `gv-`·`gvl-`·`gvt-`.
  - 버린 안: 귀여운 카드 그림, 3D 책상 사진, 어두운 배경의 폭발 효과, 세 박스가 커지는 워크플로우, 파일 형식 썸네일 박스.
  - 예시 곡 가사는 호감이 지은 문장. 실제 곡 가사는 쓰지 않는다(저작권). 성경 본문은 개역한글만 쓴다 (2026-11-24 호감 결정): 저작재산권은 2011-12-31 끝남(대한성서공회 표). 원문을 한 글자도 바꾸지 않고 출처를 적는다.
- 첫 화면 왼쪽 위 이름: 글자만 호감슬라이드 ↔ HOGAMSLIDE 로 5초마다 번갈아 나옴. 로고 그림은 고정 (2026-11-23 호감 결정).
- 문의·협업: 첫 화면 오른쪽 위 단추 → 적은 내용을 메일 앱으로 넘겨 hogamcommunity@gmail.com 으로 받음. 서버에 저장하지 않음. (서버 저장 + 알림은 나중에 다시 정함)
